================================================================================
LENS WEB — APPLICATION REPORT (SCREEN-BY-SCREEN)
================================================================================
Generated: 2026-08-01

Lens (UI brand: Vision Connect / Lens Billing & Inventory) is an optical lab ERP.
It runs the full chain: catalog → sale order → procurement/inventory → Pre-QC →
Fitting → Post-QC → dispatch → billing → accounting.

Stack:
  - Frontend: React 18 + Vite + Tailwind / shadcn
  - Backend: Express 5 + Prisma 6 + PostgreSQL
  - Auth: JWT (access + refresh), role-based permissions
  - Live refresh: WebSocket on Sale Orders / Purchase Orders

Core pipeline:
  DRAFT → (Raise PO / Issue stock) → PRE_QC → FITTING → POST_QC → DISPATCH
  → DELIVERED → INVOICE → PAID / COMPLETED

================================================================================

================================================================================

Area                  | What it covers
----------------------+----------------------------------------------------------

                      | locations/trays, categories

Seeded roles: Admin, Sales, Inventory, Accounts.

3.2 Sale Orders
--------------------------------------------------------------------------------

### List — /sales/orders

Features:
  - Add Order (opens form in new tab)
  - Search (order no, customer, customer ref)
  - Filters: status, customer, date range
  - Sortable paginated table
  - Live refresh via WebSocket SALE_ORDER_UPDATED
  - Columns: Order #, Customer, Ref No, Lens, Category, Date, RX/STOCK type,
    Status (click → history), Delete
  - Status history dialog
  - Delete confirm dialog

### Form — /sales/orders/add | edit/:id | view/:id (fullscreen)

Header actions:
  - Create / Update Order
  - Raise PO (Draft / PO Cancelled, no active PO)
  - Cancel SO (remark required)
  - Print Invoice / Print Label (barcode via local print service)
  - Create & Raise PO / Create & Print (add mode)
  - Close & Create SO (derived child orders)
  - Go to Billing (when Delivered/Billed)
  - Credit-limit lock → entire form read-only when limit exceeded

Order Information:
  - Customer, order date, delivery schedule
    (auto lead days: STOCK ~2d, RX ~3d)
  - Urgent flag, remarks, customer ref (uniqueness check), item ref
  - Flags: Only Lens / Free Lens / Free Fitting
  - Applicable offers after Calculate Price:
      PERCENTAGE, VALUE, EXCHANGE_COATING_PRICE, EXCHANGE_PRODUCT,
      EXCHANGE_BRAND_PRICE, COATING_PROMOTION
  - Derived orders links

Lens Information:
  - Type, Category, Lens, Fitting, Material, Tinting, Coating, Index
  - Stock availability preview (R/L) after price calc

Eye Specifications:
  - Both / Right / Left
  - SPH, CYL, Axis (required if CYL set), ADD, Dia
  - Validation ranges; ADD for bifocal/progressive

Pricing:
  - Calculate Price (needs customer + lens + coating + ≥1 eye)
  - Lens price, R/L extras, fitting, tinting
  - Additional custom charge rows
  - Category discount on lens price only; offer math; free lens/fitting
  - Total breakdown card

Other:
  - Status progress bar + history
  - Raise PO modal (vendor, eyes, RX/STOCK)
  - FIFO stock-pick modal (legacy/alternate path)
  - Reset from reject/scrap → Draft
  - Credit lifecycle: SO reserves credit → invoice moves to outstanding
    → payment clears

3.3 Inventory (Stock Godown & RX Godown)
--------------------------------------------------------------------------------
Routes:
  /inventory/stock/dashboard | inward | request-queue | transactions | stock
  /inventory/rx/dashboard    | inward | request-queue | transactions | stock

Same 5 tabs per godown:

Dashboard:
  - Counts, reserved (soft FIFO), low stock, value, trends
  - Initialize stock wizard

Inward Queue:
  - Pending PO receipts to put away
  - QC return Reuse / Dispose

SO Request Queue:
  - SOs needing stock
  - Issue & Pre-QC
  - Alternate Lens
  - Raise PO on shortage
  - Queue badges (PO received, QC return, scrap, etc.)

Transactions:
  - INWARD_PO, INWARD_DIRECT, OUTWARD_SALE, TRANSFER, ADJUSTMENT, DAMAGE, etc.

Stock Summary:
  - Pivot / expandable list by power
  - Filters; Excel/PDF export

Extra:
  - New Transaction page
  - FIFO StockPickModal
  - Tray capacity on inward
  - Item add/edit/view pages
  - Legacy redirects from /inventory/* → stock paths
